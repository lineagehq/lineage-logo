# Participant task prompts — candidate study v1

Use only the installed app, its shipped instructions and normal help. Work with the supplied synthetic logo. You may explore and undo. The observer cannot give procedural help; you may stop at any time. This is a baseline study of the product, not a speed test.

1. Start in the supplied fresh local project and workspace. Create or import the supplied Seatify logo without overwriting the original.
2. Ask the available local producer for the prepared logo proposal. Inspect the proposed artwork at normal and small sizes. State whether the proposed change is pending, accepted or saved. Reject it and request the correction described in the supplied agent brief.
3. Inspect the corrected proposal, then accept it and save. State whether the artwork is now accepted and whether it has been saved. Find the saved result.
4. Find the North seat. Recolor the base shapes of the North, Northeast and Southeast seats to `#d14468`, and align those three shapes to a common left edge. Preserve the rest of the logo.
5. Change the tagline to `A better seat for everyone`. Leave this manual correction unsaved for the next task.
6. Ask the local producer for the narrow adjustment described in the supplied follow-up brief, keeping your manual seat and tagline changes. Review and accept the result. Check whether your manual changes remain.
7. Save the current logo. State whether it is saved and locate that result. Stop and restart the application process, then reopen the saved logo. Confirm your changes survived.
8. Export the mark and wordmark separately as SVG files. Find both exported results and inspect them. Keep the accepted logo intact.

The agent brief and follow-up brief are candidate-bound study assets supplied only after their public product flow passes technical acceptance. Missing briefs mean the study is not ready to run.

# D1 module integration contract

These modules are an implementation candidate, not a completed D1 receipt. Browser decoding/rendering, restart, integrated history continuity and independent review remain required.

## Server

Import `saveNamedVersion` from `src/server/named-versions.ts`. Add origin-checked POST `/api/named-versions` before generic dispatch, with the same origin policy/error JSON and body limit as the existing iteration endpoint. Body: `{sourcePath: string, name: string, svg: string}`. Validate request shape; pass canonical authorized workspace root. Successful return is `{collection:"iterations",name,path}`; send 201. Never accept a root path from request input. Name collision is an actionable failure, never replacement or suffixing without the user's knowledge.

The function validates passive SVG, checks the source exists in the workspace, rejects a symlinked iterations directory, atomically links a fully written temporary file, and removes its temporary file on failure/success. Reserved portable names and paths fail before writes. No editor history APIs are involved.

## Main

Import `AssetExportController` from `src/client/export/controller.ts`, construct once, and connect a visible “Save version / export” button to `.open(button)`.

`current(): {svg, sourcePath}` must use the editor's existing clean serialization and authoritative selected source. Refuse with an actionable Error if no document, recovery undecided, pending proposal, provisional decision, save in flight, or any other state in which the saved snapshot would be ambiguous. It is called again on each action (never silently export stale dialog-opening content). Export is read-only and must not invoke dirty/reset/selection/history callbacks.

`namedVersion(name, context)` POSTs the exact supplied context to the endpoint. Refresh the workspace file list after success and return `{path}`. Do not auto-open that file, reset history, clear dirty state, or relabel the active current file: this action creates an explicit named copy. The dialog states that editing history stays unchanged and exposes the saved relative path. Root integration must ensure asynchronous file list refresh does not reset the current editor.

## CSS / accessibility

`.asset-export-dialog` needs responsive max-width (e.g. min(34rem, calc(100vw - 2rem))), bounded max-height with overflow, visible labels/controls, adequate spacing/contrast and an accessible backdrop. Native showModal provides focus containment, Escape closes except during work, and close returns focus to the invoking button. PNG control labels are explicit and include 16/32/64/512 square sizes and transparent/white/black backgrounds. Target choices are existing IDs (full, mark layer, wordmark layer), not inferred invented logo content.

## Deliberate limitations

Text stays text; missing primary fonts produce an error rather than silently exporting fallback glyphs. Local font detection uses two fallback metric comparisons; generic families are valid. Font outlining and ICO are not implemented. Stylesheet rules, font shorthand/variables, filters, markers and images are refused with corrective instructions because bounds or external-resource rendering cannot be guaranteed. Gradients, masks, clipping paths and local defs references remain supported. Shared references outside defs must be moved into defs before a subset export. A preview fallback is always an export error, never a whole-document file mislabeled as a mark.

Subset bounds use the existing independent clean-copy geometry measurement and retain its 8% longest-edge padding; ancestor transforms and required resource ancestry are preserved. PNG rendering sets explicit square intrinsic SVG dimensions before image decoding, preventing distortion caused by stretching a browser-default SVG viewport. Full SVG retains its viewBox and vector content; PNG meet alignment letterboxes wide/tall artwork.

The installed journey is now implemented in `tests/e2e/installed-exports.spec.ts` and passed on macOS at `06caa3bf48cef50c515beef89dd85bc32e1fb47f`. It packs and installs into an empty consumer, saves/reopens a named dirty copy, refuses collisions and invalid names, preserves original bytes, dirty state, selection and undo/redo, independently parses full/mark/wordmark SVG, decodes resource PNG pixels and checks eighteen wide/tall PNG size/background combinations. The full Linux suite passed 111 scenarios at `31b764930d386229ac6b48a30e8fe66d3ff01479`; later export repairs require final Linux/CI confirmation.

Independent correctness, tests, contracts/types, silent-failure and documentation review found three export defects before merge: cropped percentage coordinates, fonts on referenced text, and font inheritance through use. Each was freshly validated, repaired, and independently checked in Chromium. Percentage outputs match absolute-coordinate controls pixel-for-pixel across offset, wide and tall viewBoxes. Missing-font cases refuse while available and explicitly overridden fonts export successfully. Subset export now requires a positive finite original viewBox, retaining that viewport inside an outer crop. Font validation follows use inheritance, including nested instances, and refuses cyclic use references.

## Executable gates

- PR and main retain Node 22 verify/typecheck/unit/build, production audit, full Chromium,
  Firefox/WebKit critical journeys and Ubuntu/macOS packed install/reinstall.
- Critical journeys exercise actual pointer selection, drag, collective resize and rotation,
  text/paint, persisted save/reopen, comparison images, exact rejection, network interruption,
  reconnect and accepted saved proposals. The semantic/keyboard smoke remains.
- Chromium runs axe on empty, creation, editing, multi-selection, recovery, agent review and
  SVG/PNG export states. Serious/critical findings fail. Existing actual 200% Chromium zoom,
  panel resize keyboard/focus-return and manual tranche keyboard journeys remain in full QA.
- Node **24.20.0** additionally runs full check and packed install/reinstall. Support was
  verified at implementation against the official Node archive and Release schedule by the
  integrating owner; Node 22 remains the existing compatibility line.
- Representative corpus on every PR: wide, transparent-white, inherited-paint, resources,
  text-heavy, transformed Seatify and empty. Each original and saved/reopened result is
  rendered into the same 256px viewport and all RGBA samples compared; original bytes must
  remain unchanged. Nonempty fixtures must actually produce painted pixels. A use-only
  resource fixture intentionally has no editable geometry; its named-version save/reopen
  still preserves every pixel. Empty SVG explicitly has zero layers, transparent pixels and
  disabled ordinary Save (there is no edit to save). Neither case is silently skipped.
- `npm run test:e2e:corpus` selects the complete hash-validated public corpus, including
  100/500/1000-layer fixtures. It runs weekly Monday 08:17 UTC and on explicit dispatch in
  `Extended quality evidence`. The same workflow runs the portable D3 **measurement-only**
  command. A green measurement upload is not a comparable B0 performance acceptance result.
- `release-check.ts --candidate-receipt` records SHA256, byte length, source commit, package
  version, Node and platform for the exact artifact installed and reinstalled. The artifact
  is never published. Existing protected release and registry workflows are untouched.
- YAML is parsed in unit tests to verify real triggers, job/matrix inventory, commands,
  read-only permissions, Node selection, corpus command and nonpublishing boundaries.

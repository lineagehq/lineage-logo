# Support

Public beta issues and usage questions belong in the
[GitHub issue tracker](https://github.com/lineagehq/lineage-logo/issues).

Support is best effort with no response-time SLA. A good
report should include the Lineage Logo version, operating system, Node.js version,
browser engine, the command and exit code, and the smallest safe reproduction.
Do not include SVG contents, private workspace paths, bearer tokens, registry
files, or other secrets. Security concerns requiring confidentiality cannot be
accepted during this beta. Public issues may contain only non-sensitive
hardening discussions; withhold confidential vulnerability details.

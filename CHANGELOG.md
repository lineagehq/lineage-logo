# Changelog

All notable changes to Lineage Logo will be documented here.

## 0.1.0-beta.1 — Unreleased

- Added the distributable `lineage-logo` CLI with launch, submit, doctor, help,
  version, human-readable, and versioned JSON output modes.
- Added owner-only multi-instance discovery with explicit workspace and instance
  selection and fail-closed ambiguity handling.
- Added semantic, atomic agent review with durable, source-preserving continuation
  saves and bounded explicit draft recovery.
- Established `examples/seatify-constellation.svg` as the canonical 44-layer QA
  fixture.
- Added isolated package checks, complete Chromium QA, narrow Firefox/WebKit
  critical smoke coverage, bounded keyboard/semantic accessibility checks, and
  sanitized metadata-only failure diagnostics.

The fresh-install Seatify walkthrough and local macOS/Linux package evidence are
complete. Publication remains pending observed release-candidate CI and separate
authorization to publish. This beta intentionally has no private vulnerability-
reporting channel; see `SECURITY.md` before release.
